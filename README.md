# v2x-speed-underreporting

Repository for the paper

> J. Park and S. Jeon, "Speed Under-Reporting Below the Plausibility Threshold: A Per-Window Blind Spot in V2X Misbehavior Detection," submitted to *IEEE Transactions on Vehicular Technology*, 2026.

Mobility Cyber Security Laboratory, Kookmin University, Seoul, Republic of Korea.

## Status

The materials are being prepared for release. This repository currently holds this description only; the contents listed below will be added here.

## Planned contents

- **Code**: the scripts that build the target pool, apply the manipulation, run the rule layer and the learned detectors, and produce the tables and figures.
- **Number list (MANIFEST)**: one row per number reported in the paper, with the result file that holds it and the script that produced it.
- **Result files**: the summaries and logs that the number list points to.
- **Preregistration documents**: the documents that fixed hypotheses and decision criteria before the experiments, with their recorded hashes and a list of departures.

Until the materials are added, they are available from the authors on request.

## Data

This repository will not redistribute any dataset. The experiments use the following public datasets, which should be obtained from their original sources:

- R. W. van der Heijden, T. Lukaseder, and F. Kargl, "VeReMi: A dataset for comparable evaluation of misbehavior detection in VANETs," in *Proc. SecureComm*, 2018.
- J. Kamel, M. Wolf, R. W. van der Heijden, A. Kaiser, P. Urien, and F. Kargl, "VeReMi Extension: A dataset for comparable evaluation of misbehavior detection in VANETs," in *Proc. IEEE ICC*, 2020.
